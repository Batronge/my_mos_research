##  Описание исследования

В рамках данного исследования был проанализирован механизм, с помощью которого некоторые мобильные приложения определяют наличие активного VPN-соединения через проверку имен сетевых интерфейсов ОС Android. С этим столкнулся один из моих знакомых и поведал мне при очередной беседе. Меня заинтересовал тот факт, что обыкновенное сплит-туннелирование не решает проблему плашки на весь экран:

<img width="618" height="1439" alt="image" src="https://github.com/user-attachments/assets/3bbf28ed-48a4-4435-a533-928ebb5ff590" />

Решено было разобраться. Скачал приложение с РУстора (версия 4.24), декомпилировал с помощью ApktoolGUI и начал шариться по коду с помощью jadx-gui в поиске возможных совпадений по вызовам методов. Если кратко, то приложение глупо перебирает все имеющиеся сетевые интерфейсы и сравнивает каждый из них с неким черным списком:
